# Eventbrite

Demonstrating event booking system in a full stack project for getting hands-on awareness in some concepts.

## Stack

### Frontend
- React
- TypeScript
- React Router
- TanStack Query
- Tailwind CSS

### Backend
- Java 21
- Spring Boot 3.x
- Maven
- Spring Data JPA
- Hibernate
- Spring Security
- JWT Authentication

### Database & Storage
- PostgreSQL
- Redis

### Architecture
- Modular Monolith (initial implementation)
- Microservices (future evolution)
- REST APIs
- Domain-oriented module structure

### Messaging & Distributed Systems
- Apache Kafka (future implementation)

### DevOps & Infrastructure
- Docker
- Docker Compose
- Kubernetes (future implementation)

### Testing
- JUnit 5
- Mockito
- Testcontainers (future implementation)

### Development Tools
- Git
- Postman
